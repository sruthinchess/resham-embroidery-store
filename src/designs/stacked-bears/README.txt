==============================================================
Stacked-Bears
==============================================================

Brown bear, panda and polar bear stacked on top of each other

Finished size : 53.2 mm x 90.0 mm (2.09 x 3.54 in)
Stitch count  : 6745
Colours       : 5
Trims         : 159
Fill density  : 0.30 mm row spacing, 3.0 mm stitch length (dense tatami)
Underlay      : edge run on every shape
Fits hoop     : 100 x 100 mm (4 x 4 in) or larger
